스킨 바꾸는 기능 언제나오여? ㅋㅋ
[추가됨]
- Minecraft 닉네임으로 스킨을 불러오는 기능을 추가했습니다.
- 토글 스위치가 다른 토글 스위치에 종속된 것을 UI에 시각적으로 표시했습니다.
- 여러 새로운 조작 방식을 추가했습니다. 목록은 다음과 같습니다.
  - 팔만
  - 다리만
  - 자동
  - 자동 분노
[수정됨]
- 데이터를 불러올 때 토글 스위치 종속을 무시하던 문제를 해결했습니다.
  - 이제 토글 스위치가 종속으로 걸릴 때 지연 시간이 없습니다.
- 이제 마우스를 숨기려면 M키를 0.478723초동안 누르고 있어야 합니다.
- 일부 UI 메시지가 변경되었습니다.
  - "토스트 메시지 꺼짐" 토글 스위치 메시지는 이제 "토스트 알람 꺼짐"으로 표시됩니다.
  - "토스트 메시지 켜짐" 토글 스위치 메시지는 이제 "토스트 알람 켜짐"으로 표시됩니다.
  - 튜토리얼 메시지 "눌러서 마우스 숨기기 토글" 은 이제 "유지해서 마우스 숨기기 토글"으로 표시됩니다.
- '잔상' 조작 방식의 잔상이 이제 현재 스킨으로 모습이 바뀝니다.
- '잔상' 조작 방식의 잔상은 이제 두 배의 프레임 보간을 가집니다.
  - 따라서 더 촘촘하게 잔상이 나옵니다.
- 시작 시 경고 출력이 더욱 놀라울 정도로 빠르게 지나갑니다.
  - 따라서 더 촘촘하게 잔상이 나옵니다.
