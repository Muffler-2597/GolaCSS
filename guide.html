게임 메뉴 UI를 그대로 가져다 쓰는 CSS + JS 키트
-시작하기-

폴더째 복사하고 두 줄만 넣으면 끝. 빌드 없음, 의존성 없음.

<link rel="stylesheet" href="gola.css"> <script src="gola.js"></script>

SDF 캔버스 렌더러까지 쓰면 한 줄 추가.

<script src="gola-sdf.js"></script>

클래스 없이 쓰고 싶으면 gola-classless.css를 뒤에 한 줄 더 연결하세요. 그냥 태그가 게임 모양으로 바뀝니다(이미 기본 적용, 빼려면 <body data-gola-off>).

직접 단 .gola-* 클래스가 항상 이기니, 기존 꾸밈과 섞어 써도 깨지지 않아요.

클래스리스는 기본 켜짐이에요. body에 gola-auto가 자동으로 붙어요. 라벨은 <label>로 감싸면 한 줄 행이 됩니다. 토글 들어간 행은 30px, 일반 행은 24px.

<body data-gola-off> <!-- 자동 적용 끄기 --> <div data-gola-vol><label>마스터 <input type="range" data-ch="vol" data-label="vM" min="0" max="100" step="1" value="100" aria-label="마스터 볼륨"><output id="vM">100%</output></label></div> <label><input type="checkbox" checked> 토스트 알람 켬</label>

토스트는 gola.js 그대로라서 data-gola-toast-text만 달면 됩니다. 추가 JS 없어요.

복붙 예제는 이 페이지에 다 있어요.

-버튼-

눌러도 모양이 안 바뀌는 게 정상. 원본이 그래요 (재시작만 hover 틴트 있음).

<button class="gola-btn">버전 정보</button> <button class="gola-btn gola-btn--sm">작은 버튼</button> <button class="gola-btn gola-btn--apply">적용</button> <button class="gola-restart">재시작</button>
-토글-

JS 없이 동작. 문구까지 같이 바뀌게 하려면 data-gola-text 한 줄.

토스트 알람 켬
스킨 유형
<input type="checkbox" class="gola-check" id="g1" checked aria-label="토스트 알람"> <label class="gola-switch" for="g1"><span class="gola-knob"></span></label> <span class="gola-label" data-gola-text="켬|끔" data-gola-for="g1">켬</span>
-슬라이더-

채움 표시와 % 표기는 gola.js가 알아서. 범위는 0~100 정수(step 1), 표기는 CeilToInt+%.

마스터100%
<div data-gola-vol> <input type="range" class="gola-slider" data-ch="vol" data-label="gdM" min="0" max="100" step="1" value="100" aria-label="마스터 볼륨"> <span class="gola-vol-val" id="gdM">100%</span> </div>
-입력-

값 입력 100px, HEX 110px, 닉네임 350px. HEX는 3/4/6/8자리 (알파 무시), 틀리면 자동으로 복원됨.

<input type="text" class="gola-value" value="1.0" maxlength="6" aria-label="값 입력"> <input type="text" class="gola-hex wide" value="#FF8000" maxlength="9" aria-label="HEX 색상"> <input type="text" class="gola-input" maxlength="16" placeholder="Minecraft 닉네임 입력..." aria-label="마인크래프트 닉네임">
-토스트-

버튼에 속성만 달면 진짜 토스트가 뜸. 알람 토글로 일반 토스트를 막을 수 있고, force는 뚫고 나옴. 정적 data-gola-toast="#id" 경로는 allow 게이트를 거치지 않음(스포너 전용 게이트).

토스트 알람
<button data-gola-toast-text="스킨을 불러왔습니다." data-gola-toast-color="gola-toast--gold">골드</button> <!-- 직접 호출: golaToast("메시지", "gola-toast--red", true) -->
-대사-

화면 아래에서 한 줄씩 타이핑해요. 버튼에 속성만 달면 됩니다. 새 대사가 오면 바로 덮어씀 (줄 서서 기다리기 없음).

<button data-gola-say-text="여기가 백도어다." data-gola-say-color="#FFD700">말 걸기</button> <!-- 직접 호출: golaSay("대사", "#FFD700", 2200) --> <!-- 줄큐(화면별 hold 적용 다화면 큐, 50ms/자 기준 자동 진행): --> golaSay([{text:"첫 줄",color:"#fff",hold:2200},{text:"둘째 줄",color:"#FFD700",hold:2200}]); <!-- 잔류: golaSay("대사", "#fff", "Infinity") — 최종 Infinity 해제는 Esc 2회·더블클릭·golaSayClear() (단일 클릭·단일 Esc는 잔류) --> <!-- 글자당 사운드: window.golaSaySound = function(ch,i){} -->

글자는 50ms씩 한 자씩 (원본 textInterval 0.05), 클릭하면 전문이 바로 표시되고 hold 뒤에 다음 화면/페이드돼요. 머무름 기본 2200ms, data-gola-say-hold로 조절. 기본 firstWait 0=즉시 (원본 첫만남 1000/기타 250은 opts.firstWait로, 포크 명시). 글리프는 기본 페이드 없이 즉시 표시, 나타나기 연출이 필요하면 data-gola-say-appear.

다화면 큐·잔류·글자당 사운드 지원해요. 예: data-gola-say-queue='[{"text":"첫 줄","color":"#fff","hold":2000}]' (구 {t,c,h} 별칭도 됨). hold에 "Infinity"를 주면 버튼까지 잔류 (중간 화면 클릭=다음 화면, 최종 화면은 Esc 2회·더블클릭·golaSayClear()로 닫기). 글자마다 window.golaSaySound(ch,i,screenIdx) 또는 opts.onChar 훅이 불려요. 직접 호출: golaSay(["화면1","화면2"]) / golaSay({screens:[...]}, {hold:2200}).

-모달-

풀스크린 흰 모달. ×◀▶ 버튼 위치까지 원본 그대로. 버전 표기(.gola-modal-ver #FF8000 on 흰배경)는 원본 색상 재현이라 large-text 대비 약 2.5:1로 WCAG AA-large 3:1에 미달 — 색상은 원본 유지. 고대비 opt-in: 조상에 .gola-high-contrast를 달면 버전 표기는 #7A3E00+굵기·밑줄(약 8:1)로, .gola-desc·미체크 .gola-label(적색 2.02:1 미달)·스킨 미체크 라벨(2.34:1 미달)은 흰색+굵기·밑줄로 전환.

-API-
호출설명
golaToast(메시지, 색, force)토스트를 띄움. 색은 gola-toast--yellow / gold / red. force가 참이면 알람 꺼짐 상태에서도 표시.
golaSay(대사, 색, hold)아래에서 타이핑. 색 기본 #fff, hold 기본 2200ms("Infinity" 잔류 가능), 간격 기본 50ms/자. 배열·{screens}로 다화면 큐 재생, 새 호출이 바로 덮어씀. 클릭=타이핑중 전문 표시, hold중 다음 화면/닫기. 글자당 window.golaSaySound/onChar 훅.
data-gola-say-text / color / hold버튼에 달면 클릭 시 대사 재생. 예: data-gola-say-text="여기가 백도어다." data-gola-say-color="#FFD700".
<body data-gola-off>클래스리스 자동 적용 끄기. 직접 단 .gola-*가 항상 이김.
<label>로 감싸기라벨 한 줄 행. 토글 들어간 행은 30px, 일반 행은 24px. 문구 교체는 data-gola-text="켬|끔".
.gola-grid카드 나열. repeat(auto-fit, minmax(280px, 1fr)), gap 16px.
golaSDF.render(canvas, {text, size, color})캔버스에 SDF 텍스트를 그림. data-* 속성으로도 자동 초기화됨.
data-gola-fit감싼 요소가 부모폭을 넘으면 자동으로 축소.
data-gola-text="켬|끔"토글과 연결된 라벨 문구를 상태에 따라 교체.
.gola-stf--jiggle붙이면 뚝딱거리는 지터 애니메이션. 기본은 정지.
.gola-press눌림 opt-in. 클릭 시 0.30s 단상 유지 (원본 ButtonPressAnimation 축소 0.15s+복원 0.15s 합 0.30s의 단상 포크).
data-gola-toast="#id"클릭 시 지정 토스트를 3.5초 표시 (원본 Show 3.5s). 스포너 버튼(data-gola-toast-text)과 다른 정적 경로.
data-gola-sub="부모ID"종속 토글 (V1.7). 부모 off면 자식 강제 off + 자식 disabled(포커스·조작 불가) + 행 dim, on이면 해제.
data-gola-say-queueJSON [{text,color,hold}] 다화면 큐 (구 {t,c,h} 별칭 수용). hold "Infinity" 잔류, interval/first-wait/appear 속성 지원.
data-gola-modal-open / close클릭 시 지정 모달 열고닫기. 예: data-gola-modal-open="#gdModal". 열 때 첫 포커스 이동·닫을 때 반환, Esc·Tab 트랩 지원.
data-gola-allow체크 해제 시 일반 토스트 차단 (원본 ToastMessageAllow). force 토스트는 통과.
data-gola-vol스코프 안 볼륨 슬라이더 값을 % 라벨에 동기화. 예: <div data-gola-vol>…data-ch="vol" data-label="vM"…</div>.
data-gola-rgb스코프 안 슬라이더·값입력·HEX·미리보기 동기화. 예: <div data-gola-rgb>…data-ch="r|g|b"…</div>. .gola-vol-val은 건드리지 않음.
data-gola-nick-apply닉네임 적용 버튼. 빈값이면 빨강 차단토스트, 있으면 골드 로딩토스트 후 성공토스트(성공 문구는 "○○ 스킨을 불러왔습니다." 어순). 동일 닉네임 연속 적용 시 로딩 생략·성공만 (원본 HasCachedSkin 간이 재현). 로딩 1.2s 창 내 재클릭은 동일·다른 닉·캐시 여부 무관 침묵 (원본 fetchSkin!=null 재현). 원본 실패 토스트(error 0/1별 빨강 force)는 네트워크 영역이라 미지원. 베어 input 8종(text/email/number/password/search/tel/url/무type)도 조회 (.gola-slider/.gola-hex/.gola-value 제외). 공백만 입력도 빈값 차단(원본 IsNullOrEmpty보다 강한 포크).
data-gola-cycle / modes스위치박스 모드 순환. 예: data-gola-cycle="1" data-gola-modes="기본,관성,뚱뚱남".
data-gola-img이미지 토글 그림 교체. 예: data-gola-img="onSrc|offSrc".
golaSayClear()대사 박스 즉시 비우기 (예약 타이머 무효화).
.gola-loading / .gola-credit-*로딩 검정판(.gola-loading-title 70/.gola-loading-info 40)·우측 크레딧 힌트(.gola-credit-hint)·CREDIT 타이틀/설명(.gola-credit-title 80/.gola-credit-desc 40). CREDIT 견본은 타이포 대조실(index s-type)에, 전 마크업 예는 복붙 모음(s-more) 참조.
