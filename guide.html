게임 메뉴 UI를 그대로 가져다 쓰는 CSS + JS 키트
-시작하기-

폴더째 복사하고 두 줄만 넣으면 끝. 빌드 없음, 의존성 없음.

<link rel="stylesheet" href="gola.css"> <script src="gola.js"></script>

SDF 캔버스 렌더러까지 쓰면 한 줄 추가.

<script src="gola-sdf.js"></script>

클래스 없이 쓰고 싶으면 gola-classless.css를 뒤에 한 줄 더 연결하세요. 그냥 태그가 게임 모양으로 바뀝니다(이미 기본 적용, 빼려면 <body data-gola-off>).

직접 단 .gola-* 클래스가 항상 이기니, 기존 꾸밈과 섞어 써도 깨지지 않아요.

토스트는 gola.js 그대로라서 data-gola-toast-text만 달면 됩니다. 추가 JS 없어요.

복붙 예제는 이 페이지에 다 있어요.

-버튼-

눌러도 모양이 안 바뀌는 게 정상. 원본이 그래요.

<button class="gola-btn">버전 정보</button> <button class="gola-btn gola-btn--sm">작은 버튼</button> <button class="gola-btn gola-btn--apply">적용</button> <button class="gola-restart">재시작</button>
-토글-

JS 없이 동작. 문구까지 같이 바뀌게 하려면 data-gola-text 한 줄.

토스트 알람 켬
스킨 유형
<input type="checkbox" class="gola-check" id="g1" checked> <label class="gola-switch" for="g1"><span class="gola-knob"></span></label> <span class="gola-label" data-gola-text="켬|끔" data-gola-for="g1">켬</span>
-슬라이더-

채움 표시와 % 표기는 gola.js가 알아서. 범위는 0~100.

마스터100%
<input type="range" class="gola-slider" data-ch="vol" data-label="gdM" min="0" max="100" step="1" value="100"> <span class="gola-vol-val" id="gdM">100%</span>
-입력-

값 입력 100px, HEX 110px, 닉네임 350px. HEX는 3/4/6/8자리 (알파 무시), 틀리면 자동으로 복원됨.

<input type="text" class="gola-value" value="1.0"> <input type="text" class="gola-hex wide" value="#FF8000"> <input type="text" class="gola-input" maxlength="16" placeholder="Minecraft 닉네임 입력...">
-토스트-

버튼에 속성만 달면 진짜 토스트가 뜸. 알람 토글로 일반 토스트를 막을 수 있고, force는 뚫고 나옴.

토스트 알람
<button data-gola-toast-text="스킨을 불러왔습니다." data-gola-toast-color="gola-toast--gold">골드</button> <!-- 직접 호출: golaToast("메시지", "gola-toast--red", true) -->
-모달-

풀스크린 흰 모달. ×◀▶ 버튼 위치까지 원본 그대로.

<button data-gola-modal-open="#gdModal">버전 정보 열기</button> <div class="gola-modal" id="gdModal"> <div class="gola-modal-head"> <div class="gola-modal-title">TypeGolaSimulator</div> <div class="gola-modal-ver">V1.7</div> <button class="gola-modal-btn close" data-gola-modal-close="#gdModal">×</button> </div> <div class="gola-modal-log">...</div> </div>
-SDF 텍스트-

게임과 같은 글자 질감. 아틀라스에서 직접 찍는 캔버스 방식.

<canvas class="gola-sdfcv" data-text="GolaGola" data-size="40" data-color="#fff"></canvas>

-API-
호출설명
golaToast(메시지, 색, force)토스트를 띄움. 색은 gola-toast--yellow / gold / red. force가 참이면 알람 꺼짐 상태에서도 표시.
golaSDF.render(canvas, {text, size, color})캔버스에 SDF 텍스트를 그림. data-* 속성으로도 자동 초기화됨.
data-gola-fit감싼 요소가 부모폭을 넘으면 자동으로 축소.
data-gola-text="켬|끔"토글과 연결된 라벨 문구를 상태에 따라 교체.
.gola-stf--jiggle붙이면 뚝딱거리는 지터 애니메이션. 기본은 정지.
